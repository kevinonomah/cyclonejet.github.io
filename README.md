# AssistManager landing page

A static landing page for **AssistManager**, a bookkeeping concept for small
businesses with sales, purchases and inventory books and a monthly financial
report. Built in 2023 with plain HTML and CSS.

**Live:** https://kevinonomah.github.io/cyclonejet.github.io/

This is a front-end mockup: the feature pages behind each "book" were not
built, so the navigation links scroll to the matching section of the page.

## Files

| File | Purpose |
|---|---|
| `index.html` | The landing page |
| `amdemo_.html` | Redirect from the page's original URL |
| `images/` | Logo, icons and hero background |
